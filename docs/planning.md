# LifeLedger(생활 장부) — 돈 · 계정 · 파일 · 일정을 한곳에 두는 1인용 장부

> 작성 2026-10-13 · 상태: **운영 중인 앱의 디자인 개편 기획** — 기능은 이미 있다(1단계 기능 정리 · 2단계 이름 변경 완료, `develop`).
> 공개 준비 전체 순서는 [archive/2026-10-13-public-release-plan.md](archive/2026-10-13-public-release-plan.md) 4단계(끝남). 구조 · API · DB 는 [architecture.md](architecture.md) · [api.md](api.md) · [erd.md](erd.md).
> 이 문서는 Claude 디자인에 현재 화면 캡처와 같이 넣는다. 시안 · 점검 문서는 [design/](design/) 에 둔다.

## 0. 한 줄 정리

수입 · 지출 · 예적금 · 투자 · 구독(돈), 사이트 계정과 비밀번호(보관함), 서류 파일, 결제일 · 만기 · 할일(일정)을
**한 사람이 한 앱에서** 관리한다. 비밀번호 · 2FA 시크릿은 AES-256-GCM 으로 암호화해 두고, 열람할 때마다 기록이 남는다.
홈서버에서 운영하고, 휴대폰에서는 PWA 로 쓴다.

```text
[재무]                       [보관함]                       [일정]                  [관리]
 가계부 (수입/지출 ·          계정 보관함 (비밀번호 ·          캘린더 (직접 일정 +       보안 · 알림 · 시스템 로그 ·
  예적금 · 투자)               TOTP · 백업코드, 암호화)         구독 결제일 · 만기 연동)   코드 관리 · 설정
 구독 관리                     파일 보관함 (B2)
 자산 종합 (순자산 추이)
            └──────────── 대시보드: 이번 달 돈 흐름 + 다가오는 결제 · 만기 · 일정 ────────────┘
```

## 1. 누가 · 어떻게 보나

| 보는 사람 | 상황 | 디자인에 주는 뜻 |
| --- | --- | --- |
| 본인 (실사용) | PC 와 휴대폰을 오가며 매일 짧게 — 지출 기록, 비밀번호 꺼내기, 결제일 확인 | 자주 하는 동작(지출 추가 · 계정 열람 · 복사)은 2번 안에 끝나야 한다. 휴대폰 폭이 1급 |
| 면접관 (데모) | 데모 계정으로 들어와 3 ~ 5분 둘러본다. 클론 · 실행은 하지 않는다 | 대시보드 첫 화면이 앱 전체를 설명해야 한다. 데모라는 표시와 샘플 데이터가 어색하지 않게 |

## 2. 화면 구조

### 2.1 지금

- 데스크톱: 왼쪽 고정 사이드바(248px) + 위쪽 TopBar(60px, 페이지 이름 · 통합 검색 · 알림 종 · 테마 전환) + 본문(최대 1200px).
- 휴대폰: 사이드바는 접히고 아래쪽 BottomNav 4칸(홈 · 가계부 · 보관함 · 더보기 → 사이드바 열기).
- 사이드바 메뉴 (순서 고정):

  | 그룹 | 메뉴 |
  | --- | --- |
  | (맨 위) | 대시보드 |
  | 금융 | 가계부 · 구독 관리 · 자산 종합 |
  | 보관함 | 계정 보관함 · 파일 보관함 |
  | 도구 | 캘린더 |
  | 시스템 | 보안 · 알림 · 시스템 로그 · 코드 관리 · 설정 |

### 2.2 지금 구조의 문제

- '도구' 그룹에 캘린더 하나뿐이다. '시스템' 에 성격이 다른 다섯 개(보안 · 알림 · 로그 · 코드 · 설정)가 몰려 있다.
- BottomNav '보관함' 이 파일 보관함으로 간다 — 더 자주 쓰는 건 계정 보관함이다.
- TopBar 왼쪽 페이지 이름이 바로 아래 h1 과 같은 말을 반복한다.
- (정리함 2026-10-13) 메뉴는 '자산 관리', 검색 · 설정 · 대시보드 바로가기는 '가계부' 로 섞여 있던 것을 **가계부** 로 맞췄다 — '자산 관리' 와 '자산 종합' 이 헷갈리기도 했다.

### 2.3 시안에서 정할 것

- 그룹 다시 묶기 — 예: 재무(가계부 · 구독 · 자산 종합) / 보관함(계정 · 파일) / 일정(캘린더) / 관리(보안 · 알림 · 로그 · 코드 · 설정). 알림은 TopBar 종으로 충분하면 메뉴에서 빼도 된다.
- BottomNav 4 ~ 5칸 구성 (홈 · 자산 · 계정 · 일정 · 더보기 안).
- TopBar 가 페이지 이름 대신 무엇을 보여 줄지 (빵부스러기 · 빈칸 · 빠른 추가 버튼 등).

## 3. 화면별

공통: 목록은 데스크톱 표 → 휴대폰 카드, 아래에 페이지 번호 + 10/20/30개 선택. 삭제는 확인 창. 모달은 Esc · X 로만 닫힌다(바깥 클릭 무시 — 입력 중 날아가지 않게).

### 3.1 로그인

- 카드 하나: 로고 · "LifeLedger가 지켜드리는 것" · 특징 3줄(AES-256 암호화 · 비밀번호 없는 로그인 · 제3자 공유 없음) · Google 로 계속하기 · (펼침) 이메일 인증코드 로그인(6자리).
- 허용 목록 밖 계정이면 경고 상자.
- **데모에서 추가**: "데모로 둘러보기" 버튼(5단계). 실제 로그인과 헷갈리지 않는 위치 · 무게로.

### 3.2 대시보드

- 지금: 숫자 카드 5개(이번 달 지출 · 수입 · 순자산 · 활성 구독 · 저장된 계정) — 4열 격자라 5번째가 혼자 줄바꿈된다.
  그 아래 왼쪽 '최근 활동' · '다음 달 고정지출 예측'(구독 + 반복지출), 오른쪽 '다가오는 만료 · 마감'(D-day) · '다가오는 일정', 맨 아래 '빠른 실행' 3칸(4열 격자라 한 칸 빈다).
- 차트가 없다.
- **바라는 것**: 첫 화면 한 장으로 "이번 달 돈 흐름 · 곧 빠져나갈 돈 · 곧 다가오는 날짜" 가 보이게. 면접관이 처음 보는 화면이다.
  - 숫자 카드 개수와 격자를 맞춘다.
  - '다가오는 만료 · 마감' 과 '다가오는 일정' 이 겹친다 — 하나의 타임라인으로 합쳐도 된다.
  - 수입 · 지출 흐름이나 순자산 추이를 작은 차트로 넣어도 된다.
  - 위젯 켜고 끄기는 없앴다 — 고정 배치.

### 3.3 가계부 (수입/지출 · 예적금 · 투자) — 가장 복잡한 화면

탭 3개, 머리 버튼 하나(탭에 따라 '항목 추가' · '예적금 추가' · '투자 항목 추가').

#### 수입 / 지출 (가장 자주 쓰는 탭)

- 숫자 카드 4개(수입 · 지출 · 실소비 · 잔액), "자산이동은 실소비가 아니다" 안내 한 줄.
- 즐겨찾기 줄: 자주 쓰는 수입 · 지출 버튼 — 누르면 오늘 날짜로 추가 창이 채워져 열린다. 등록 · 관리(▲▼ 순서).
- 월별 지출 막대 차트 + 자동이체 설정 목록(일시정지 · 재개 · 수정 · 삭제) 나란히.
- 엑셀 줄(양식 · 업로드 · 내려받기) → 조회 조건(기간 + 1/2/3개월, 유형, 카테고리 2단, 검색) → 합계 줄 → 표 10열(번호 · 유형 · 카테고리 · 내역 · 결제수단 · 금액 · 메모 · 날짜 · 관리).
- 추가 창: 유형(지출 · 수입 · 자산이동) · 날짜 · 내역 · 대/소분류 · 금액 · 결제수단(지출) / 입금 은행(수입) / 이동 대상(자산이동) · 메모.
- 자동이체 설정 창: 위 + 시작일 · 반복 주기 · 요일/기준일/월 · 주말 처리 · 활성 — 길다.

#### 예적금

- 숫자 카드 4개(총액 · 이번 달 납입 · 평균 금리 · 만기 임박), 조회 조건, 표 13열 — 너무 넓다.

#### 투자

- 숫자 카드 3개, 투자 계좌 카드(원화 · 달러 예수금, 보유 종목 수, 만기, 환전 · 수정 · 삭제), 반복매수 설정 목록.
- 표 11열 + 줄마다 매수 · 매도 · 시세조회 버튼. 해외 종목이 있으면 USD/KRW 전환.
- 투자 항목 추가 창이 앱에서 가장 길다(수익 · 수익률로 원금 역산 도우미 포함).

**바라는 것**: 수입/지출 탭은 '빨리 기록하기'(즐겨찾기 · 추가)가 맨 앞. 예적금 · 투자 표는 핵심 열만 남기고 나머지는 상세로. 긴 입력 창은 단계나 묶음으로 나눈다.

### 3.4 구독 관리

- 숫자 카드 4개(월 합계 · 연 환산 · 활성 건수 · 다음 결제까지 N일), 무료 체험 종료 임박 경고(지금 해지).
- 검색 → 카드 격자: 서비스명 · 카테고리 · 상태(활성 · 체험 · 일시정지) · 금액/주기 · 다음 결제일 D-n · 결제수단 · 수정 · 해지.
- 추가 창: 서비스명 · 카테고리 · 금액 + 통화 · 주기 + 다음 결제일 · 상태 · 결제수단 · 마지막 사용일 · 메모.
- **바라는 것**: 결제일 순서가 한눈에(이번 달 결제 달력 띠나 타임라인). 오래 안 쓴 구독(마지막 사용일) 강조.

### 3.5 자산 종합

- 읽기 전용. 큰 순자산 숫자 + 지난달 대비(내려가도 초록색 — 고칠 것), 자산 구성 도넛, 자산 종류별 카드, 6개월 순자산 막대.
- **바라는 것**: 추이 차트를 주인공으로. 늘고 줄어든 색을 구분.

### 3.6 계정 보관함 — 보안 기능의 얼굴

- 2FA 미설정 경고, 엑셀 줄(내려받기는 "평문 포함" 확인), 카테고리 + 검색, 표(서비스 + URL · 카테고리 · 아이디 · 수정일 · 관리).
- 행을 누르면 상세 창: 아이디(복사) · 비밀번호(가림 → 보기 · 복사, 설정한 시간 뒤 자동으로 다시 가림) · TOTP 6자리 + 남은 초 · 백업코드(보기 · 생성 · 재생성 · 전체 복사) · 메모.
- 마스터 잠금이 켜져 있으면 열람할 때 잠금 해제 창이 뜬다(서버가 423 응답 → 전역 창 → 풀면 원래 요청을 다시 보낸다). 열람은 '보안' 화면의 최근 열람에 남는다.
- 추가 창: 서비스명 · URL · 카테고리 · 아이디 · 비밀번호(생성 버튼 · 강도 막대) · TOTP · 메모, 저장 버튼 "저장 (암호화)".
- 지금 문제: 잠금 상태 표시와 '지금 잠그기' 버튼이 없다. 추가 창의 비밀번호 입력이 평문으로 보인다.
- **바라는 것**: 복사가 가장 빠른 동작. 잠금 상태(잠김 · 풀림 · 남은 시간)가 화면 위에 보이게. "암호화되어 있다 · 열람이 기록된다" 가 과하지 않게 드러나도록(면접 소재).

### 3.7 파일 보관함

- 머리 버튼 3개(폴더 생성 · 폴더 업로드 · 파일 업로드), 사용량 막대(10GB 중 n%), 끌어다 놓기 영역, 업로드 진행, 경로(빵부스러기) + 폴더 ZIP 받기 · 비우기, 검색(전체 · 현재 폴더), 폴더 타일 · 파일 카드(이모지 썸네일 + 확장자, 보기 · 다운 · 삭제).
- 보기 창: 이미지 · PDF 미리보기, 그 밖은 다운로드.
- **바라는 것**: 목록 보기 / 격자 보기 전환. 이미지는 실제 썸네일 자리. 휴대폰에서 머리 버튼 3개를 하나로.

### 3.8 캘린더

- 안내 상자, 월 이동 줄(‹ 연 · 월 › 오늘), 월 격자(종류별 색 칩 — 결제 빨강 · 만기 파랑 · 만료 주황 · 할일 초록 · 공휴일 빨강, 연동 일정은 점선 + ◈, 음력은 🌙), 오른쪽 '다가오는 일정' · 범례 + 공휴일 표시 토글.
- 휴대폰: 칩 대신 색 점 4개 + "+n", 누르면 그날 목록.
- 상세 창(수정 · 삭제 — 연동 일정은 원래 화면에서 수정), 추가/수정 창(제목 · 날짜 · 유형 · 음력 · 반복 · 반복 종료일 · 메모).
- **바라는 것**: 날짜 칸을 누르면 그날 목록 + 추가가 같이. 연동 일정과 직접 일정의 구분을 색 말고 모양으로도.

### 3.9 보안

- 로그인 기기 / 세션(현재 기기 · 미확인 표시, 로그아웃 · 차단, 전체 로그아웃) → 보안 설정(암호화 방식 · 세션 자동 만료 · 비밀번호 자동 숨김 · 마스터 잠금 설정/해제 + 자동 잠금 시간) → 최근 열람 10건.
- 지금 문제: 최근 열람이 동작 코드(`vault_disable` · `export:backup` 등)를 그대로 보여 준다(3단계에서 한글로). '잠금 해제' 가 여기선 "잠금 기능 끄기", 보관함 창에선 "잠긴 것 풀기" — 말이 겹친다.
- **바라는 것**: 면접관이 "이 앱은 보안을 어떻게 다루나" 를 보는 화면. 세션 · 잠금 · 열람 기록 세 덩어리가 분명하게.

### 3.10 알림

- 필터(전체 · 가계부 · 시스템), 선택삭제 · 전체삭제 · 모두 읽음, 목록(안 읽음 점 · 종류 아이콘 · 제목 · 시간 · 출처) — 본문은 상세 창에서만.
- 지금 문제: 열기만 해도 "읽음 처리했습니다" 토스트가 뜬다.
- **바라는 것**: 목록에서 본문 첫 줄이 보이게. 알림이 결제 · 만기 · 파일 · 로그인 중 무엇인지 아이콘으로 구분.

### 3.11 시스템 로그

- 수준(전체 · 정보 · 경고 · 오류), 조회 조건(기간 · 카테고리 · 검색), 펼침 목록(수준 · 카테고리 · 메시지 · 시각 → 펼치면 상세 항목 키/값).
- 예약 작업(알림 · 순자산 스냅샷 · DB 백업 · 투자 현재가 · 구독 결제일 갱신 · 공휴일 · 휴지통 정리)의 실행 기록이 여기 쌓인다.
- **바라는 것**: 오류 · 경고가 먼저 눈에 띄게. 예약 작업별 마지막 성공 시각 요약(서버 `/_meta` 에 이미 있다)을 위에 두는 것도 후보.

### 3.12 코드 관리

- 선택박스 항목을 종류별(가계부 카테고리 · 결제수단 · 구독 카테고리 · 투자 유형 · 예적금 유형 · 은행/기관 · 계정 카테고리)로 관리 — 자산 유형은 어느 화면도 읽지 않아 2026-10-20 탭에서 뺐다. 투자 · 예적금 유형은 값이 고정이라 이름 · 순서 · 숨김만 반영. 끌어서 순서, 수정 · 비활성 · 삭제, 기본값 복원, 아래에 추가 줄(코드 · 표시명). 가계부 카테고리는 대/소분류 2단.
- 지금 문제: 영문 코드가 칩으로 앞에 나오고, 줄마다 글자 버튼 3개라 빽빽하다.
- **바라는 것**: 표시명이 주인공, 코드는 흐리게. 줄 버튼은 아이콘이나 더보기 메뉴로.

### 3.13 설정

- 세로 탭 2개: 프로필(내 계정 · 표시 이름, 알림 토글 — 이 기기 푸시 + 테스트 발송 · 만기/결제 임박 · 파일 업로드 완료) / 데이터(내보내기 — 가계부 엑셀 · 계정 JSON · 전체 ZIP, 가져오기 — 계정 JSON 복원, 위험 구역 — 계정 삭제).
- 탭이 2개뿐이라 세로 탭이 과하다 — 한 페이지에 묶음으로 나열해도 된다.

## 4. 공통 요소 — 시안도 이 단위로 그린다

시안을 받으면 공통 요소부터 바꾸고 화면을 바꾼다. 화면 코드는 공통 요소만 쓰도록 테스트로 막혀 있다(`frontend/__tests__/ui-conventions.test.ts`).

| 요소 | 지금 있는 변형 |
| --- | --- |
| 페이지 머리 `PageHeader` | 제목 · 설명 · 오른쪽 버튼 · (아이콘) |
| 버튼 `Button` / `IconButton` | primary · ghost · danger · solid-danger · link / 크기 sm · md · lg · inline, 로딩 |
| 카드 `Card` · 숫자 카드 `StatCard` | 머리 · 몸통, 호버 / 아이콘 · 값 · 이름 · 변화(오름 · 내림), 색 4가지 |
| 배지 `Badge` | success · warning · danger · neutral · blue |
| 탭 `Tabs` · `Segmented` | 밑줄 · 세로 / 알약 · 묶음 |
| 입력 `Field` · `SearchInput` · `Toggle` · 체크박스 | 이름표 · 필수 · 오류 |
| 모달 `Modal` · `ConfirmModal` | sm · md · lg, 부제목 · 머리 버튼 · 바닥 / 위험 · 일반, 입력 붙는 확인 |
| 조회 조건 `FilterPanel` · 엑셀 줄 `ExcelToolbar` · 페이지 번호 `Pagination` | |
| 빈 상태 `EmptyState` · 로딩 · 오류 `QueryError` · `ErrorBanner` | |
| 설정 묶음 `SettingGroup` / `SettingRow` | 이름 · 설명 · 오른쪽 조작 |

지금 섞여 있는 것 — 시안에서 하나로 정한다:

- 검색: 가계부 · 로그는 `FilterPanel` + '조회' · '초기화', 구독 · 계정 · 파일은 따로 만든 상자 + '검색'.
- 아이콘: SVG 아이콘 세트와 이모지(📅 📦 ⏰ 💸 ⏳ 🔁 ◈ 🌙 🔐, 테마 전환 🌙/☀️)가 섞여 있다 → **SVG 하나로**.
- 목록 모양: 표 · 카드 격자 · 줄 목록 · 타일이 화면마다 다르다(번호 열도 있다 없다).

## 5. 디자인 방향

### 5.1 지금 토큰 (`frontend/app/globals.css`)

| 항목 | 값 |
| --- | --- |
| 강조색 | `#00C07F` (초록) — 수입 · 성공 색과 같다 |
| 배경 · 표면 · 테두리 | `#FFFFFF` · `#F8F9FB` · `#E4E7EC` / 다크 `#0D1117` · `#161B22` · `#30363D` |
| 글자 | `#0F1923` · `#4B5768` · `#9AA5B4` |
| 의미 색 | 위험 `#F04438` · 경고 `#F79009` · 파랑 `#3B82F6` · 호박 `#F59E0B` |
| 글꼴 | 제목 Syne · 본문 DM Sans · 숫자 DM Mono — **한글 글꼴 지정이 없어** 한글은 시스템 글꼴(맑은 고딕)로 나온다. Geist 는 불러오지만 쓰지 않는다 |
| 모서리 · 그림자 | 8px(`rounded-ui`) · 14px(`rounded-panel`), 그림자 3단(card · raised · overlay) |
| 폭 | 사이드바 248px · 머리 60px · 본문 최대 1200px |

### 5.2 바라는 것

- **차분한 개인 장부.** 숫자가 많은 앱이라 숫자 글꼴 · 정렬(오른쪽 · 고정폭)과 표 밀도가 중요하다. 장식보다 읽기.
- **한글 글꼴을 정한다** (예: Pretendard). 숫자 전용 글꼴은 유지하거나 한글 글꼴의 고정폭 숫자로.
- 강조색: 지금 초록이 '수입 · 성공' 과 같은 색이라 의미가 겹친다 — 강조색을 바꾸거나 수입 색을 따로 둔다.
- 다크 모드 유지. 휴대폰 폭(390px)에서도 같이 그린다.
- 차트 라이브러리가 없다(막대 · 도넛은 CSS). 시안에서 차트가 더 필요하면 그려 주고, 라이브러리는 구현 때 정한다.
- 돈 색 규칙: 수입 · 지출 · 자산이동 · 늘어남 · 줄어듦을 정해 두고 화면 전체에 같은 색을 쓴다.
