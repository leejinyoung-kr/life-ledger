# LifeLedger 디자인 개편 점검

> 2026-10-13 · 대상: 이 폴더의 `life-ledger-main.html` · `life-ledger-components.html` · `life-ledger-modals.html`(추가분, §9) · `source/` (Claude 디자인 결과물)
> 기준: `docs/planning.md` §2 ~ §7, Claude 디자인에 넘긴 프롬프트, 지금 develop 코드
> **판정: §6 D1 ~ D9 · §9.5 D10 모두 권고대로 확정 (2026-10-13).** 이 문서가 4단계 구현의 기준이다 — 시안과 이 문서가 다르면 이 문서를 따른다.
> 방법:
>
> - `source/*.dc.html` 를 끝까지 읽었다.
> - 번들 HTML 을 로컬(127.0.0.1)에 띄워 13개 화면을 모두 보고, 모달·검색·더보기 메뉴도 열어 봤다. 데스크톱 1440 · 휴대폰 390, 라이트 · 다크.
> - 글자 대비와 막대 높이는 브라우저에서 직접 쟀다.
> - 시안에 나오는 기능은 하나씩 실제 frontend · backend 코드와 대조했다.

## 0. 결론

방향은 받는다. 기획서가 바란 것을 거의 다 풀었다.

- 강조색(금빛)과 돈 색을 나눴다.
- 숫자는 오른쪽 정렬 · 고정폭.
- 아이콘은 SVG 하나로 통일했다.
- 메뉴를 다시 묶었다.
- 구독 결제 순서 띠, 보관함 잠금 띠, 캘린더 날짜별 목록.

**그대로 옮기면 안 되는 것이 세 부류 있다.**

| 구분 | 건수 | 어디 |
| --- | --- | --- |
| 시안 자체의 결함 (구현 때 고칠 것) | 15 | §3 |
| 실제 앱과 다르게 그린 것 (시안을 고치거나 판정) | 12 | §4.2 |
| 정할 것 (확정함) | 9 | §6 |

가장 큰 것 세 가지:

1. **글꼴이 명조(Noto Serif KR)다.** 기획서는 "한글 글꼴을 정한다(예: Pretendard)" 였다. 시안은 제목 · 본문 · 표를 모두 명조로 했고, 고딕은 대안으로만 두었다. → 판정 D1.
2. **라이트 모드 주 버튼 글자 대비가 3.0 : 1 이다.** WCAG AA 기준 4.5 : 1 에 못 미친다. 금빛 테두리 버튼의 글자가 금빛(`#B68235`)이라서다. → §3-2, 판정 D2.
3. **막대 차트 높이가 실제 값과 다르게 그려진다.** 대시보드 · 가계부 월별 지출은 6 ~ 9월 막대가 모두 같은 높이다. → §3-1.

## 2. 요청 대비

| 요청 (기획서 · 프롬프트) | 결과 | 비고 |
| --- | --- | --- |
| 공통 요소 시트 먼저, 토큰표 맨 앞 | ✅ | §4 단위 그대로 |
| 13개 화면 HTML 하나, 다크 · 390 전환 | ✅ | 로그인 포함 14 |
| 새 기능 넣지 말고 따로 적기 | △ | `제안 목록.md` 로 따로 뺐다. 하지만 시안 안에도 실제와 다른 것이 섞였다 (§4.2) |
| 화면 이름 · 한글 문구 유지 | ✅ | 메뉴 이름 그대로. 설명 문구 일부를 다듬었다 |
| SVG 아이콘만, 이모지 금지 | ✅ | Lucide 한 세트(선 1.6). 지금 앱은 직접 그린 SVG 41개 + 이모지 |
| 한글 글꼴 지정 (예: Pretendard) | △ | **명조**(Noto Serif KR) + 제목 Cormorant Garamond · 본문 Lora. Pretendard 는 Tweaks 대안으로만 |
| 숫자 고정폭 · 오른쪽 정렬 | ✅ | `tabular-nums`. 단 제목 글꼴 숫자 문제가 있다 (§3-3) |
| 강조색을 수입 · 성공 색과 분리 | ✅ | 강조 금빛 `#B68235`. 돈에는 쓰지 않는다고 못 박았다 |
| 돈 색 한 벌 | ✅ | 수입 `#2F6A4C` · 지출 `#A3412E` · 자산이동 `#47607E` · 경고 `#A65A12`. 부호(+ − ⇄ ▲ ▼)가 항상 같이 간다 |
| 커리어노트(남색 ink)와 다른 인상 | ✅ | 실제 커리어노트 관리자 화면은 Pretendard + 남색이다. 다만 커리어노트 **시안**도 같은 디자인 시스템(Cormorant · Lora · Noto Serif KR)이었다 — 명조를 고르면 두 앱 시안의 결이 비슷해진다 |
| 차분한 장부, 장식보다 읽기 | ✅ | 바탕은 종이색, 머리카락 선, 카드에 그림자 없음 |
| §2.3 메뉴 묶음 · 아래 메뉴 · TopBar | ✅ | 아래 표 |

§2.3 에서 정하기로 한 것은 시안이 이렇게 정했다.

- **메뉴 묶음:** 대시보드 / 돈(가계부 · 구독 관리 · 자산 종합) / 보관함(계정 · 파일) / 일정(캘린더) / 관리(보안 · 알림 · 시스템 로그 · 코드 관리 · 설정). 알림은 메뉴에 남기고 개수 배지를 붙였다.
- **휴대폰 아래 메뉴 5칸:** 홈 · 가계부 · 계정 · 일정 · 더보기. '보관함 → 파일' 문제(§2.2)가 풀린다. 더보기는 아래에서 올라오는 전체 메뉴 시트다.
- **TopBar:** 페이지 이름을 빼고 "가계부 · 계정 검색 Ctrl K" 상자 + 종 + 테마로 바꿨다. h1 과 같은 말을 반복하던 문제(§2.2)가 풀린다.

## 4. 실제 앱과 대조

### 4.1 화면만 바꾸면 되는 것 (데이터 · API 있음)

| 시안 요소 | 근거 |
| --- | --- |
| 대시보드 '월별 지출' 막대 | 가계부의 월별 지출 추이 API(최근 5개월)를 다시 쓴다 |
| 대시보드 '다가오는 날짜' 하나로 합치기 | 지금 '다가오는 만료 · 마감'(구독 결제 · 예적금/투자 계좌 만기) + '다가오는 일정'(직접 입력 — 할일 · 서류 만료 포함)을 앞에서 합친다. **단 직접 일정은 서버가 4건만 준다** |
| 대시보드 숫자 카드 아래 문구(다음 결제 D-n · 2FA 미설정 N개 · 지난달 대비) | 대시보드 API 에는 없다. 구독 · 계정 · 자산 API 를 같이 부르면 된다 (요청이 늘어난다) |
| 구독 '10월 결제 순서' 띠, 표 모양 목록 | 구독마다 다음 결제일이 있다 |
| 구독 '마지막 사용' 열, "90일 넘게 안 쓴 구독 N건" | `last_used_at` 이 있다. 지금은 입력만 받고 보여 주지 않는다 |
| 계정 목록 2FA 열 | 화면이 이미 2FA 미설정 개수를 센다 — 목록 데이터에 있다 |
| 보관함 잠금 띠(풀림 · 남은 시간) + 지금 잠그기 | 잠금 해제 응답에 `expiresIn` 이 온다. 지금 잠그기는 메모리 토큰만 지우면 된다. 기획서 §3.6 에서 바란 것 |
| 계정 내보내기 "내려받기 입력" 확인 | 입력 붙는 ConfirmModal 이 있다(파일 '비우기'에서 씀). 지금은 단순 확인창 |
| 계정 추가 창 묶음 나누기 + 비밀번호 가림 | 지금은 `type="text"` 라 평문으로 보인다(§3.6 문제) — 고치는 쪽이다 |
| 캘린더 날짜 누르면 옆에 그날 목록 + 추가 | 월 단위로 이미 받는다. 기획서 §3.8 에서 바란 것 |
| 캘린더 연동/직접 구분을 모양으로(점선 + 연결 아이콘) | 지금은 ◈ 이모지 |
| 알림 목록에 본문 첫 줄 | 목록 API 가 `desc` 를 준다 — 지금은 상세 창에서만 보인다 |
| 알림 종류 아이콘 | 출처 값(구독 · 예적금 · 보안 · 계정 보관함 · 파일 보관함 · 투자)으로 나눈다 |
| 보안 최근 열람 한글 이름 · `::1 (이 기기)` | 프론트 이름표만 늘리면 된다 (동작 8종 중 5종이 영어 그대로 — 3단계 작업과 같다) |
| 코드 관리: 표시명이 주인공, 코드는 흐리게, 더보기 메뉴 | 화면만 |
| 설정 한 페이지 묶음 | 화면만. 시안에 '가져오기 — 가계부로 이동' 이 빠졌다 — 구현 때 넣는다 |
| 파일 격자/목록 전환 | 화면만. 목록 모양은 그려지지 않았다 (§3-15) |
| 사이드바 알림 개수 | TopBar 종이 이미 개수를 받는다 |
| 휴대폰 모달 → 아래에서 올라오는 시트 | 공통 Modal 변경 |

| 5 | 자동이체 | 자산이동의 이동 대상 · 대상 항목이 필수(*) | 둘 다 선택이다. 첫 항목이 "연동 없음(단순 기록)" (`:998-1011`) | 별표를 빼고 "연동 없음" 선택지를 둔다 |
| 6 | 자동이체 | 소분류에 별표가 없다 | 소분류도 필수 (`:987`) | 별표 |
| 7 | 예적금 추가 | 오류 예시 "4,5 → 소수점은 마침표로" | 금리는 `type="number"` 칸이라 쉼표가 들어가지 않는다 | 오류 예시는 상품명 비움 같은 실제 검사로 |
| 8 | 일정 추가 | 날짜 아래 "음력" 체크칸만 있다 | "🌙 음력 날짜로 반복" — 켜면 매년 음력 반복이고, 반복 선택지가 음력용으로 바뀐다. 아래에 설명 한 줄이 붙는다 (`calendar/page.tsx:481-494`) | 이름표는 "음력 날짜로 반복" (아이콘은 moon SVG), 설명 한 줄 유지 |
| 9 | 일정 추가 | 반복 종료일이 늘 보인다 | 반복이 '없음' 이 아닐 때만 보인다 (`:496`) | 실제대로 |
| 10 | 알림 상세 | "구독 관리로 이동" 주 버튼 | 알림에는 링크 필드가 없다. 출처 글자(`source`)뿐이다 | 판정 D10 |

### 9.3 아직 안 그린 창 — 다시 요청하지 않고 시트 규칙으로 만든다

- **투자 매수 / 매도 창** (`InvestTab.tsx:534, 584`)
  - 칸: 단가(시세조회로 자동입력) · 수량 · 필요 금액 / 환입 금액 · 예수금 한도 안내.
  - 주 1 ~ 2회 쓰는 창이다. 반복매수 창(§9 m3)의 md 520 모양과 같은 틀로 만든다.
- **가계부 즐겨찾기 등록 · 관리 창** (`LedgerTab.tsx:569-661`) — 관리 창의 ▲▼ 순서 버튼은 코드 관리의 끌기 손잡이 모양으로 맞춘다.
- **그 밖:** 계정 수정, 백업코드 보기 · 재생성, 코드 이름 수정 등. 이미 그린 창과 같은 틀이다.
