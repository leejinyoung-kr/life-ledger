# 0004. DB 마이그레이션은 배포 워크플로가 컨테이너 교체 전에 자동 적용

- **상태**: 채택 (소급 기록)
- **결정일**: 2026-06-26 (근거 커밋 `8290951`) · 한 번 뺐다가 2026-08-01 되돌림 (`45e92a3`)
- **기록일**: 2026-10-18
- **결정 방식**: AI 제안을 그대로 채택 — 당시 대안 검토는 없었다. 다만 수동 적용을 한 달 남짓 써 본 뒤 되돌린 이력이 있다

## 맥락

- 스키마는 Prisma 마이그레이션(`backend/prisma/migrations/`)으로 바뀐다. 운영 DB 에 **언제 · 누가** 적용할지 정해야 했다.
- Fly.io 시절(2026-06-20)에는 `fly.toml` 의 `release_command = "npx prisma migrate deploy"` 가 배포마다 돌았다. 홈서버로 옮긴 첫 워크플로(`f0d2ee1`)에는 이 단계가 없었다.

## 지금 코드에 남은 것

- [.github/workflows/deploy-home-server.yml](../../.github/workflows/deploy-home-server.yml) — `docker compose build` → `run --rm --no-deps backend node dist/config/check-env.js` → `run --rm backend npx prisma migrate deploy` → `crypto-check` → `up -d`. backend 를 안 빌드한 배포에서도 매번 돈다 ("변경 없으면 즉시 끝남")
- 데모 인스턴스도 같은 순서 (워크플로 「Deploy demo」)
- 마이그레이션 SQL 은 `--create-only` 로 만든 뒤 컬럼 코멘트를 손으로 넣는다 (워크스페이스 공통 규칙)
- 마이그레이션 파일을 init 하나로 합친 적이 세 번 있다 — `a67d85c`(06-06) · `2d6e9a5`(06-15) · `21c1bbf`(07-13)

## 지금 검토 — 대안 비교 *(AI 초안 · 본인이 읽고 고친다)*

| 대안 | 장점 | 단점 | 이 프로젝트에 대입하면 |
| --- | --- | --- | --- |
| 수동 적용 (06-27 ~ 08-01 에 쓴 방식) | 적용 전에 사람이 SQL 을 본다. 시점을 고른다 | 잊는다. 새 코드가 옛 스키마로 뜬다 | 실제로 "깜빡하기 쉬워서" 되돌렸다 |
| **지금**: 워크플로가 `up -d` 전에 1회성 컨테이너로 `migrate deploy` | 빠뜨리지 않는다. 실패하면 교체 전에 멈춘다 | 마이그레이션이 끝나고 새 컨테이너가 뜰 때까지 **옛 코드가 새 스키마로 돈다** — 컬럼 · 테이블을 지우는 변경은 그 사이 옛 코드를 깨뜨린다. Prisma migrate 에는 되돌리기(down)가 없다 | 사용자 1명이라 몇 분 오류는 감수할 수 있다 |
| 앱이 부팅하며 스스로 migrate | 단계가 하나 준다 | 인스턴스가 여럿이면 경합. 실패하면 앱이 안 뜬다 | 이 레포는 이미 "새 컨테이너 부팅 시 재암호화" 를 하고 있어 부팅 일이 더 늘어난다 |
| 확장 → 축소 두 번 나눠 배포 (expand/contract) | 무중단 | 배포가 두 번, 규율이 필요하다 | 1인 앱엔 과하다. 지우는 변경(2026-10-13 기능 제거 같은)에만 쓰면 된다 |

- **지금 보니 맞는 점 (초안)**
  - 실패하면 `up -d` 전에 멈추는 순서라, 마이그레이션 실패가 곧 서비스 중단으로 이어지지는 않는다.
  - "사람이 기억해야 하는 단계" 를 없앴다.
- **아쉬운 점 · 위험 (초안)**
  - 적용 전 백업이 워크플로에 없다. 매일 04시 덤프(`db-backup`)가 있지만 배포 직전 상태는 아니다. 큰 변경 때는 손으로 덤프를 떴다 (공개 준비 계획 0단계 · 이름 전환).
  - 마이그레이션을 init 하나로 세 번 합쳤다. 운영 DB 의 `_prisma_migrations` 이력은 어떻게 맞췄는지 기록에서 찾지 못했다 (확인 필요).
  - 마이그레이션 SQL 을 사람이 보지 않고 배포된다. 손으로 고친 SQL(코멘트 · 행 삭제)이 섞여 있다.
