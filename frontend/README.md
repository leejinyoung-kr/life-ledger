# DocNexus — Frontend

Next.js (App Router) 기반 웹 클라이언트

## 실행

```bash
# 의존성 설치 (루트에서)
pnpm install

# 개발 서버 (포트 3000)
pnpm dev
```

## 주요 명령어

```bash
pnpm dev      # 개발 서버 실행
pnpm build    # 프로덕션 빌드
pnpm start    # 프로덕션 서버 실행
pnpm lint     # 린트
```

## 구조

```text
frontend/
└── app/         # Next.js App Router 페이지
```

## 접속

<http://localhost:3000>
